# DANCE LOVE

舞蹈短视频微信小程序，以及使用同一后端的浏览器联调页面。已配置 AppID `wx102ef5b8bdcbfade`，小程序使用微信登录，浏览器保留本地演示账号。**支付功能暂时关闭**，保留上传次数限制与已有额外次数。管理员可以创建、修改和删除分类。

## 生产存储：MySQL 与腾讯云 COS

MySQL 8.0+ 表结构在 [db/mysql-schema.sql](db/mysql-schema.sql)，先执行该文件，再在 `.env` 中配置 `MYSQL_HOST`、`MYSQL_DATABASE`、`MYSQL_USER` 和 `MYSQL_PASSWORD`。COS 通过 `MEDIA_PROVIDER=cos` 启用；配置 `COS_SECRET_ID`、`COS_SECRET_KEY`、`COS_BUCKET`、`COS_REGION` 后，视频转码完成会上传为 `COS_PREFIX/videos/<视频 ID>/video.mp4` 与 `cover.jpg`。播放、封面及下载继续由本服务的短期授权链接控制。

本地开发默认使用 SQLite 和本地文件，避免没有云端密钥时无法启动。COS 的转码临时文件位于 `DATA_DIR/staging`，上传成功后自动删除。

## 本地启动

需要 Node.js 22.13 或以上（本项目在 Node.js 24.15 上测试）。首次安装需要网络，安装包会下载 FFmpeg / FFprobe，可能需要几分钟。

```powershell
cd D:\project\danceLove
npm.cmd install
npm.cmd start
```

打开 **http://127.0.0.1:8787**。右上角可以切换林同学、许老师、管理员、陈同学四个演示账号。界面中的角色切换只用于本地联调，不能作为正式登录方式。

服务默认只监听 `127.0.0.1`。视频和 SQLite 数据库保存在 `data/`，正常重启保留数据。不要把该目录提交到 Git，也不要在其中存放唯一一份重要原片。

## 微信开发者工具

1. 导入本项目根目录，配置文件为 `project.config.json`，小程序源码目录为 `miniprogram/`。
2. 当前 AppID 已配置为 `wx102ef5b8bdcbfade`，使用该小程序的开发成员账号进入开发者工具。
3. 在本机启动后端。`miniprogram/config.js` 默认连接 `http://127.0.0.1:8787`。
4. 本地调试配置已关闭合法域名校验；在开发工具中检查相同选项。正式发布必须恢复域名校验并配置 HTTPS 合法域名。
5. 真机联调需将 `baseUrl` 改成电脑的局域网 IP，并设置 `HOST=0.0.0.0` 启动后端。仅在可信的调试网络中使用，演示账号没有真实身份认证。真机访问能力取决于微信调试模式、测试号与系统网络权限。

本次未连接微信开发者工具或微信真机；小程序完成脚本/配置静态检查，登录使用模拟微信响应做了自动化测试，真实登录、媒体选帧及相册权限仍需微信环境验收。浏览器页面可以直接使用。

### 微信登录与管理员授权

AppSecret 仅保存在项目根目录的 `.env`，已被 `.gitignore` 排除，不能放进 `miniprogram/` 或版本库。`npm start` 会自动加载该文件。小程序的 `authMode` 默认为 `wechat`，通过 `wx.login` → `/api/auth/wechat` → 官方 `code2Session` 取得真实身份，服务端不向客户端返回 openid、session_key 或 AppSecret。

新微信账号默认为学员，不能自己选择角色。管理员先在小程序登录，点击首页右上角“复制账号ID”，再由本机维护者设置角色：

```powershell
# 查看已登录过的微信用户 ID（不显示 openid）
node --env-file-if-exists=.env scripts/user-role.js --list
# 将占位内容替换为需授权的真实用户 ID
node --env-file-if-exists=.env scripts/user-role.js <用户ID> admin
# 老师同理，最后一个参数使用 teacher
```

授权后下拉刷新首页即可出现审核和分类管理入口。浏览器演示用户与真实微信用户互相独立，不会自动合并作品或次数。

`.env` 当前 `APP_MODE=demo` 用于继续本机浏览器联调，同时可接收真实微信登录。面向实际用户运行时改为 `APP_MODE=wechat`，关闭演示账号入口并拒绝旧演示登录态；还需完成 HTTPS、云存储和部署验收。

## 已实现的规则

| 能力 | 学员 | 老师 | 管理员 |
| --- | --- | --- | --- |
| 观看、点赞、收藏、下载已通过且有权访问的视频 | ✓ | ✓ | ✓ |
| 上传并提交审核 | ✓ | ✓ | ✓ |
| 每日免费上传 | 1 次 | 2 次 | 不限 |
| 审核公有/私有待审视频 | — | — | ✓ |
| 普通入口访问他人已通过的私有视频 | — | — | — |

- 视频真实时长必须大于 0 且不超过 90 秒，上传文件不超过 **100 MiB（104,857,600 字节）**，界面简写为 100MB。支持 MP4 / MOV 容器，最高接受 4K 像素数；服务端读取媒体信息，不信任客户端传入时长。
- 标题为 1～8 个 Unicode 码点；分类必选，首次初始化预置中国舞、爵士舞、街舞、芭蕾、现代舞、基本功。管理员可创建一级或二级分类，最多两层；上传仅可选择没有下级的末级分类。一级分类筛选会包含其二级分类视频。删除有二级分类的一级分类前必须先处理其二级分类；删除有作品的末级分类时必须选择转移分类，保留全部视频、公私有权限及审核状态，至少保留一个分类。已删除分类不会在重启后恢复。
- 必填 1～8 个标签，每个 1～12 个字；重复标签合并，搜索匹配标题或任意标签，支持与分类组合筛选。上传标签输入框上方提供“舞蹈日常、基本功、零基础、舞台练习”四个常用标签，点击自动加入。
- 公有作品审核通过后进入发现和搜索；私有作品审核通过后仅本人可观看、下载、点赞、收藏。管理员只可通过待审入口预览私有视频，审核结束后审核链接立即失效。
- 待审和驳回作品只有本人能查看基本信息、状态和驳回原因；不能观看、下载、点赞或收藏。审核预览是必要例外。管理员上传也进入待审，可由管理员审核；本版本允许自审。
- **成功处理并提交审核时扣次数**；非法文件、超限文件、处理失败不扣。驳回不退次数，再次上传算新提交。
- 以北京时间每天 00:00 重置免费额度，免费额度不累计。每天先使用免费额度，再扣永久额外次数。
- 支付入口已隐藏，小程序充值页面不再注册，订单创建和模拟到账接口统一返回 403。已有额外次数继续有效，每日先用免费次数再扣额外次数；没有可用次数时提示明天再来。历史订单/账本结构和未注册的充值页面代码保留，以便后续恢复。
- 封面可选择视频中的时间点，服务端抽取该帧并计算画面平均色。列表将标题以诗意、律动、留白三种风格居中叠加在封面上；浅色画面用深字、深色画面用浅字。**原始封面 JPEG 不烧录标题**，标题由小程序/浏览器绘制，字体随设备而异。
- 转码为 H.264/AAC、最大 720×1280 边界框、视频限码率约 1.2Mbps、音频 64kbps，MP4 faststart 支持拖动播放。处理成功删除原始文件，仅保留压缩后播放/下载副本和封面；下载得到的是压缩版。

## 验证步骤

1. 学员上传，选择分类、标签、可见范围和封面时间，确认“我的作品”为待审核。
2. 切换管理员，在审核工作台预览，选择通过或填写原因驳回。
3. 切换学员，公有已通过视频能搜索、播放、点赞、收藏、下载；私有视频只能在本人作品里访问。
4. 切换另一学员/管理员，确认无法搜到他人的私有视频。
5. 用完免费次数且没有额外次数后上传会被拒绝；页面没有充值入口，直接调用下单接口也被拒绝。
6. 管理员进入分类管理，新增分类并改名；删除有作品的分类时选择转移目标，确认作品仍可访问，且权限未改变。

```powershell
npm.cmd test
npm.cmd run check
# 可选：生成一个三秒合成测试视频，不是真实舞蹈素材
node scripts/sample.js
```

测试生成的媒体与数据库位于临时目录并在结束后清理，不修改演示数据。`scripts/sample.js` 单独生成 `test-results/sample.mp4`。

## 项目结构

```text
miniprogram/     原生小程序：发现/作品/收藏/分类管理、上传、详情/审核
server/         Node HTTP API、SQLite 事务、视频校验/转码/截帧
web/            浏览器联调界面，与小程序共用真实 API
tests/          API 与真实媒体处理集成测试
scripts/        静态检查、合成视频工具
docs/           接口、成本、上线接入说明
data/           运行时数据（不入库）
```

环境变量可设置 `HOST`、`PORT`、`DATA_DIR`、`FFMPEG_PATH`、`FFPROBE_PATH`、`WECHAT_APP_ID`、`WECHAT_APP_SECRET`。`.env.example` 不含密钥；`npm start` 自动加载存在的 `.env`。`APP_MODE` 可为 `demo`（本地联调）或 `wechat`（仅微信身份）。两种模式的支付接口都已关闭。

详细设计见 [成本与上线方案](docs/architecture.md)、[接口说明](docs/api.md)。
